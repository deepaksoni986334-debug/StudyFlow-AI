# 📚 StudyFlow AI

An adaptive study-planning prototype that helps students organize study time and prioritize topics.

## Features

- Generate study schedules based on learning goals.
- Allocate time according to topic priorities.
- Adapt schedules to changing time availability.
- Simple, interactive web interface.

## Technologies

- Python
- Gradio

## How It Works

StudyFlow AI currently uses rule-based Python logic to distribute study time according to topic priorities.

The current version does not yet include a generative AI model, voice recognition, or Alexa integration.

## Installation

### 1. Clone the repository

    git clone https://github.com/deepaksoni986334-debug/StudyFlow-AI.git

    cd StudyFlow-AI

### 2. Install dependencies

    pip install -r requirements.txt

### 3. Run the application

    python app.py

Open the local URL displayed in your terminal.
